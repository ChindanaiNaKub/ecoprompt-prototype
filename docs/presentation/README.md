# EcoPrompt Presentation Guide (4 Presenters)

This folder is the shared presentation guide and rehearsal script for a short live demo plus Q&A.

## Recommended timing (before Q&A)

Target total: **6–8 minutes**

- Presenter 1: Opening and problem (about 1.5 minutes)
- Presenter 2: Solution and live demo (about 2 minutes)
- Presenter 3: Technical and ethical design (about 1.5–2 minutes)
- Presenter 4: Limitations, conclusion, and handoff to Q&A (about 1–1.5 minutes)

## Running order

1. Presenter 1 — `01-opening-and-problem.md`
2. Presenter 2 — `02-solution-and-live-demo.md`
3. Presenter 3 — `03-technical-and-ethical-design.md`
4. Presenter 4 — `04-limitations-conclusion-and-qa.md`
5. Any presenter — `05-professor-questions.md` (Q&A cheat sheet)
6. Any presenter — `06-demo-checklist.md` (before presenting)

## Notes for the team

- Each script includes exact sentences you can read aloud.
- Keep wording honest: EcoPrompt does **not** measure exact provider emissions.
- If you want, replace "Presenter 1/2/3/4" labels with your real names.
