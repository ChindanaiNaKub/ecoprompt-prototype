# 06 — Demo Checklist

## Pre-presentation checklist

- Confirm internet access and login state.
- Open the deployed app and keep one backup tab ready.
- Confirm all presenters know their section file.
- Keep this reminder visible: do **not** claim exact emissions.

## Demo prompts

- Simple prompt: "Summarize this paragraph in three bullet points."
- Complex prompt: "Design a secure architecture for a multi-user web application and justify key decisions."

## Live demo flow checklist

- Start with simple prompt and intentionally choose a large model.
- Show complexity result, recommendation, and low/central/high estimates.
- Click **Switch and continue** (or clearly explain if you keep current model).
- Send request and show response plus provider-reported token usage.
- Show the modelled range language carefully.
- Enter a complex prompt and show possible larger-model recommendation.

## Backup plan if live API/authentication fails

- Switch to a prepared screenshot/video sequence of the same flow.
- Explain expected steps using the section scripts.
- Clearly say: "This is a demo fallback, but the product flow is the same."
- Continue to methodology and Q&A without claiming live verification.

## Wording reminders

- Say: "modelled low/central/high operational carbon range."
- Say: "provider-reported token usage."
- Do not say: "exact carbon emissions."
