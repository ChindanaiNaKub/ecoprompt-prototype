# 04 — Limitations, Conclusion, and Q&A Handoff

**Speaker:** Presenter 4  
**Target time:** ~1–1.5 minutes

## Limitations (exact sentences)

"Our complexity classifier is rule-based, so it can misclassify some prompts."  
"Pre-send token counts are estimates, while provider-reported tokens appear after the request."  
"Our carbon values are modelled scenarios, not direct measurements from provider infrastructure."  
"The current live path depends on the configured provider and does not include a fallback provider in this prototype."

## Future improvements (exact sentences)

"Next, we would improve classification quality with broader validation data."  
"We would support more providers and stronger cross-provider comparison."  
"We would also improve deployment-scale testing and continue refining methodology assumptions."

## Conclusion (exact sentences)

"In conclusion, EcoPrompt makes hidden AI resource decisions visible and gives users practical, transparent guidance."  
"It combines explainable recommendations, modelled carbon ranges, and user control without claiming false precision."

## Handoff to Q&A

"Thank you for listening. We are ready for your questions."
