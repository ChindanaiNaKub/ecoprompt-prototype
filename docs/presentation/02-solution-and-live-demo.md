# 02 — Solution and Live Demo

**Speaker:** Presenter 2  
**Target time:** ~2 minutes

## What to say and do (exact flow)

1. **Simple prompt + intentionally large model**  
   Say: "I will start with a simple prompt and intentionally choose a large model so we can see EcoPrompt's recommendation."  
   Click/show: Enter a short prompt like "Summarize this paragraph in three bullet points," then select a large model.

2. **Complexity and recommendation display**  
   Say: "EcoPrompt detects task complexity and shows why this prompt is simple."  
   Say: "It recommends a smaller model and displays estimated tokens with low, central, and high modelled carbon scenarios."  
   Click/show: Point to complexity, reasons, recommended model, and estimate panel.

3. **Switch and continue**  
   Say: "The recommendation is advisory. The user can switch or keep the current model."  
   Click/show: Click **Switch and continue**.

4. **Send request and inspect response/token usage**  
   Say: "Now I send the request."  
   Say: "After completion, we see the response and provider-reported token usage."  
   Say: "EcoPrompt then calculates a modelled low/central/high operational carbon range from those tokens using assumptions."  
   Click/show: Send prompt, then point to response and token usage fields.

5. **Complex prompt**  
   Say: "Now I enter a more complex prompt to show that the smallest model is not always the best choice."  
   Say: "For complex tasks, EcoPrompt may recommend a larger model."  
   Click/show: Enter a complex prompt and show updated recommendation.

## Reminder line

"This demo shows right-sizing guidance, not forced automation. The user stays in control."
